# Portfolio One-Pager

Clean Neobrutalism portfolio for Florian Matthias.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push `dist/` to GitHub Pages, Netlify, or Vercel.

## Blog-Beitrag schreiben

1. Neue Datei `content/blog/mein-thema.md` anlegen (Vorlage: `content/blog/willkommen.md`)
2. `npm run dev` — Beitrag erscheint sofort unter `/blog/`
3. `npm run build` — fertige Seiten, RSS-Feed und Sitemap liegen in `dist/`
